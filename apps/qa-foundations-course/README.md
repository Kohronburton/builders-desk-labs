# QA Foundations — Builder's Desk Labs

A free, detailed, browser-first n8n workflow QA course. It follows the Builder's Desk product spine:

**Command Center → Learning Workspace → Course Modules → QA Artifact Registry → Tool Integrations → Learning Health**

## Course modules

1. Workflow anatomy and the Builder's Desk product spine
2. Items, JSON, expressions, and data contracts
3. Triggers, schedules, and webhooks
4. HTTP Request and credentials
5. Flow logic and transformations
6. Executions, pinning, and debugging
7. Error workflows, retries, and idempotency
8. AI workflows and human review
9. Security, source control, and environments
10. Deployment, scaling, and a client-ready capstone

Progress is private to the learner's browser. No accounts, analytics, secrets, or personal records are collected.

## Run and validate

```bash
cd apps/qa-foundations-course
npm start
# open http://localhost:3001
npm test
```

## Product extension points

- downloadable template pack and sample completed QA packet
- a sandbox API/database for real exercises
- Playwright starter repository and CI lesson
- optional authentication for cross-device course progress
