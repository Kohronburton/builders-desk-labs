# NOIR 01 Scroll Reveal

A compact luxury-product hero demonstrating scroll-driven storytelling for an ultra-premium cap.

## Live demo

https://noir-cap-scroll-demo.jamalburton.chatgpt.site

## What it demonstrates

- inertial, scroll-linked product motion
- staged typography and product reveal
- dynamic lighting and orange-underbrim climax
- responsive desktop and mobile composition
- reduced-motion accessibility fallback
- high-resolution WebP asset optimized to roughly 200 KB
- zero framework or runtime dependency for the portable demo

## Run locally

Open `index.html` with a local static web server. The product image is referenced from `assets/cap.webp`.
